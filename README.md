# Privacy Policy

**Effective Date:** [Insert Date]

## 1. Overview  
This Privacy Policy explains how the Custom GPT interacts with resumes and candidate information stored in our HubSpot system.

## 2. Data Access  
- The GPT fetches candidate data (e.g., resumes, contact info) from HubSpot via a secure, scoped Private App Token.  
- Only authorized users can request resume data through the Custom GPT interface.

## 3. Use of Data  
- Resumes and contact information are used solely to support recruitment workflows and review.  
- The system does not retain or store full resume data beyond the immediate session, unless explicitly specified.

## 4. Data Storage & Security  
- Access tokens are securely stored and cannot be retrieved by end users.  
- Any URLs generated for file access (signed URLs) are temporary and expire quickly.

## 5. Access Logging  
- Actions taken via the GPT (file access, contact searches) are logged in HubSpot under the Private App and user account.  
- Admins can revoke access by rotating or deleting the Private App token.
